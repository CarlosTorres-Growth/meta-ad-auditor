Meta Ad Auditor

Pulls every active ad in a Meta ad account and flags the ones that waste spend: single-product ads sending people to a collection page, ads still running old offers, and ads with missing or unexpected destinations.

Used only for requests to Meta from this page. It is never saved or sent anywhere else.

The number after act= in your Ads Manager URL.

Any active ad whose text contains one of these is flagged. Not case-sensitive. You can edit this after running the audit.

How to get an access token
  1. Open the Graph API Explorer at developers.facebook.com/tools/explorer.
  2. Pick a Meta app you have access to, then add the ads_read permission.
  3. Click Generate Access Token, approve, and copy the token into the field above.
  4. These tokens are short-lived, so generate a fresh one each time you run the audit.

Carousels and catalogue ads are marked as showing several products automatically. The API can’t tell what a single image or video shows, so look at the thumbnail and tag it One or Several. Tags are saved in this browser by ad ID. Rules: one product sent to a collection page means switch to the product page; several products sent to a single product page means review. URL types are read from Shopify-style paths (/products/ and /collections/).
